# Pitch Booking Platform — Frontend Only

This package contains the assigned pages for one developer, plus the shared frontend files needed to run the pages locally.

## Run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `frontend/pages/index.html` with Live Server (if this page is not part of your assignment, use your assigned HTML page instead).
4. This is a frontend prototype: it uses demo/mock data and does not connect to a real backend, database, or payment gateway.

## Shared files
`frontend/css/style.css`, `frontend/js/shared/api.js`, and `frontend/js/shared/main.js` are included as copies for local testing. During team integration, keep one agreed version of each shared file in the main project and merge page files by assignment. Do not overwrite teammates' page files.

## Note
The HTML and JavaScript are separated. Each page loads its corresponding page script.
